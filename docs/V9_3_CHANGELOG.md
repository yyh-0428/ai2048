# V9.3 变更

- JS 兼容引擎加入 8192 槽、128 位完整棋盘键的精确叶值缓存，命中保持原评分和节点计数。
- 出生分支改为可恢复的原地回溯，移除逐出生的两次棋盘复制。
- 行移动内部使用打包值直接查表，按既有方向顺序计算子树，减少临时对象。
- 新增叶命中/未命中诊断字段，原近似搜索 TT 清理规则不变。
- 保留普通 WASM 与 Survival 模块原始字节，模式配置、风险与 Verifier 条件保持不变。
- 页面及包版本更新到 9.3，交互和本地存档键兼容 V9.2。
- 保存上传的 V9.2 单文件基准；新增真实工作线程配对测试、压力回归和报告生成器。
- 原 benchmark/report 入口转到本版工具，避免把新结果误标为 V9.2。旧工具与 README 存档。

实测指标、对局原始结果与限制见 V9_3_BENCHMARK_RESULTS.md；方法及来源见 V9_3_RESEARCH.md。
