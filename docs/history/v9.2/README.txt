2048 AI V9.2
============

快速开始
--------
1. 完整解压文件夹。
2. macOS 双击「启动 2048 AI.command」。首次受阻时，可在 Finder 右键选择“打开”。
3. 也可以直接打开 2048-ai.html；整个游戏不依赖网络、账号或额外安装包。
4. 「停止本地服务.command」只停止本文件夹启动的服务。

怎么玩
------
方向键 / WASD / 在棋盘滑动：移动。
空格：开始或暂停自动玩；Esc：暂停；H：提示一步；M：声音开关。
撤销：当前页面会话最多保留最近 60 步；自动玩暂停后可撤销。
刷新可恢复棋盘、分数和步数，但不恢复撤销历史。
合成 2048 后可以继续冲更大的数字。

轻快：优先速度；深入：均衡思考；极致：更多残局复核。
走棋间隔只改变观看节奏，不改变搜索预算。0 ms 取消额外等待。
手机的“提示一步”和“自动玩 / 暂停 AI”固定在底部。
本局进度、最高分、强度、间隔和声音设置保存在当前浏览器本地。
清理浏览器数据会清除记录；文件模式与本地服务模式有不同的保存位置。

本次升级
--------
- 搜索调度移到独立 Worker，根方向的搜索结果通过 MessagePort 直接返回调度线程。
  页面不再处理每轮搜索消息；同轮各方向共用同一配额，按 Worker 内搜索耗时计账。
  页面绘制、动画和线程消息等待不计入加深搜索的预算。
- 保留 V9.1 已有的高速 WASM 核心、预算、阶段深度限制及 Survival + Verifier 护栏。
- 暂停、提示、切换强度和新游戏不再反复重建计算线程；同棋盘分析可复用。
- 修复旧棋盘提示、撤销后忙碌锁定、新游戏旧动画回调、停止后的旧自动计时器。
- 大数字根方向统一使用 JS 评分；修复深搜失败没有结果、
  终局被深度截断掩盖和相同最大数字的扫描偏置。
- 大数字 JS 路径直接搜索目标深度，不再反复重算 1…d；过大数字不在行查表中饱和。
- 渲染复用 16 个棋子节点；极速模式限制绘制频率；取消逐棋子的样式读取和强制布局。
- 修复隐藏结束层仍可获得键盘焦点、减少动画设置失效、按钮空格快捷键冲突。
- 相对评分不再伪装成百分比；说明区收纳实现细节；新增读屏提示和本局进度保存。
- Mac 启动地址固定为 127.0.0.1:20480，避免随机端口导致每次丢失浏览器记录；
  停止脚本校验进程身份，服务退出会清理子进程。

开发与验证
----------
运行游戏无须 Node。修改源码和复现测试可使用 Node：
  node tools/build.mjs
  node --test tests/regression.cjs tests/coordinator.cjs
  node tests/benchmark.cjs comparisons
  node tests/benchmark.cjs games 20
  node tests/benchmark.cjs resume-games 20  # 中断后按完整 seed 配对恢复

src/ 是可维护源码；2048-ai.html 是构建后的单文件应用。
tests/fixtures/v9.1.html 保留原版，用于真实源码对比；tests/fixtures/positions.json 是局面集。
docs/V9_2_REVIEW.md 记录界面、BUG、AI 分析和本次修改。
docs/V9_2_BENCHMARK_RESULTS.md 记录实测数据和证据边界。
READ_FIRST_V9_2.md 是本版开发护栏；原 V9.1 文档保留以便追溯。

实测结果与取舍
--------------
- 最终 20 组轻快 A/B：新版均分 80,516（原版 72,208）；中位分 75,916（原版 79,186）。
- >=4096：18/20（原版 15/20）；>=8192：4/20（原版 2/20）。样本仍小，不作胜率保证。
- 60 个固定局面、无额外 UI 消息延迟：极致平均响应 46.51 ms（原版 49.23 ms）；
  轻快平均响应 9.75 ms（原版 8.14 ms）。保护计算预算会增加部分模式的实际等待。
- 因此这是正确性、界面和调度的工程升级，不是“所有模式全面更快/每局都更强”的承诺。
- 20/20 组回归通过；739/739 个固定深度根方向的 WASM 分数和节点数一致。
- 所有计时均来自 Node 真实 Worker 测试，不是 Mac 浏览器实测。

限制
----
- 保留的老 WASM 评价器仍有已知阶段跳变和对称性限制，未宣称这些已经彻底修复。
- 后台标签限速、操作系统调度、设备温度与 CPU 资源竞争仍会影响实际速度。
- 当前环境禁止浏览器访问本地游戏，已做源码、DOM 状态、真实 Worker 和 WASM 验证；
  未完成真实浏览器截图/点击、移动 Safari 或 Mac 启停脚本的实际验收。
- 小样本对局只作 smoke test，不代表 4096/8192 达成率在统计上已经提高。
