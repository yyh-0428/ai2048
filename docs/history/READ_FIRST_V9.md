# READ FIRST — 2048 AI V9 开发护栏

> 继续修改 V9 前先读本文件，再读 `docs/VALIDATED_FINDINGS.md`、`docs/DECISION_LOG.md` 和 `docs/BENCHMARK_PROTOCOL.md`。

## 1. V9 当前定位

V9 不是推倒重写。它仍以 V7.2 的高速 64-bit WASM Expectimax 为主核，保留 V8 的 D4 根规范化、每轮 TT 隔离、Survival Sentinel 和 Verifier；本版重点修正 V8 对三个模式“过度统一”造成的短预算质量损失，并减少无意义的浅层重算。

用户实测反馈必须作为设计输入：V8 极致最强；自动节奏拉到最左（0ms）综合体验最好；轻快/深入仍能稳定到 2048，但继续冲 4096/8192 的表现感觉下降。注意：自动节奏只控制走棋间隔，不增加 AI 思考预算。

## 2. V9 新增硬规则

### Rule V9-A — 不再强求三个模式拥有完全相同的“质量底线”

V8 的共同参数思路本身没有错，但把深入也从 d3 起步会导致 18ms 级预算有时还没完成 d4 就结束。V9 改为：

- 轻快：保留 V8/V7-fast 的 d3/d4/d5 自适应底线；
- 深入：直接 d4，极残局 d5；
- 极致：跳过无缓存价值的 d3，从 d4 起步，极残局 d5。

共享的是正确性护栏和快速主核语义，不是强行共享相同起始深度。

### Rule V9-B — 不要把 cap7 / exactPlies2 全局恢复给深入模式

局面级对照显示，旧 strong 式 `sampleCap=7 + exactPlies=2 + 更低 probCut` 同深度成本可放大约 5 倍，但对更深参考决策的吻合提升很小，甚至在部分样本不如“同语义直接 d4”。

结论：正常搜索继续使用快速 cap4 语义；更贵的采样/精确展开只允许在少量 Survival 冲突的 Verifier 中使用。

### Rule V9-C — 快速模式不要粗暴提前到“<=7 空格强制 d4”

这个实验在 81 个局面级样本上，对更深参考的吻合率从约 63% 提升到 77.8%，看起来很好；但固定整局 seed 1 和 seed 4 都出现了分数下降。

这说明“局面级更接近深层参考”不等于“整局长期得分更高”。该实验已撤回。除非以后有更大规模整局统计证明，否则不要重新加入。

### Rule V9-D — 极致只跳过确定无价值的浅层，不强制每步直接 d5

因为 V8 每个深度轮都会清 TT，d3 不会帮助 d4/d5，跳过 d3 是安全的纯调度优化。但直接把 d5 设成无时间上限的 mandatory floor，可能重新引入“最低深度突破 budget”的旧问题。

所以 V9 极致从 d4 起步，给 d5 更多剩余预算，而不是每一步都强制完整 d5。

### Rule V9-E — 风险层是保护器，不是常驻第二主引擎

V9 增加 `Spawn Fragility Probe`：对主搜索当前最佳方向，完整枚举下一次 2/4 出生并检查 mobility；只有出现明显脆弱信号时才启动 H6/H7 Survival。

风险触发包括：

- 空格 <= 1；
- 空格 <= 3 且合法根方向 <= 2；
- 下一次出生存在立即死亡概率；
- forced-move 概率 >= 6%；
- `<=2` 合法方向概率 >= 45%；
- 某个出生结果只剩 <=1 个合法方向。

Survival 仍不能直接改动作，必须经过 Verifier。

### Rule V9-F — Verifier 可以更贵，但只能在稀有冲突时更贵

V9 的 Verifier 对两个争议候选临时升级到至少：

- sampleCap 5；
- exactPlies 2；
- exactWhenEmpty 5；
- 更低 probCut。

这是有意的“稀疏高质量计算”。不要把这套参数搬到每一步普通搜索。

## 3. 本版关键实测

### 深入模式质量底线

约 45 个正常可达中盘状态，以更深一层的相同快速搜索语义作为参考：

- V8-style 当前 floor：约 84.4% 与参考最佳方向一致；
- 仅把 strong 直接从 d4 起步：约 91.1%；
- 平均测试成本约从 2.85ms 增至 5.18ms（单线程顺序跑所有根方向，仅用于相对比较）。

### 过度恢复旧 strong 参数不划算

同类测试中，恢复 cap7/exactPlies2 的候选平均成本约 36.7ms，而与更深参考一致率只约 80.6%。因此撤回。

### 快速提前 d4 的反例

`<=7 empties -> d4` 的局面级参考吻合率显著提高，但同 harness 固定 seed：

- seed 1：V8 baseline 约 78.9k，实验版约 69.3k；
- seed 4：V8 baseline 约 74.6k，实验版约 71.4k。

因此不发布该规则。

### 极致浅层浪费

在 37 个中盘样本上，按 V8 的隔离 TT 语义顺序重算 d3+d4+d5，与直接 fresh d5 相比，前者总时间约多 35%。V9 不直接 mandatory d5，但据此安全地跳过极致的 d3。

## 4. 仍然有效的 V8 硬规则

以下规则全部继续有效：

- 不为“架构漂亮”接受明显性能倒退；
- 自动节奏不是思考时间；
- 近似 TT 不跨 refinement round 污染；
- 保持 D4 对称性；
- 禁止 hard phase switch 让 evaluator 尺度跳变；
- Survival 不直接夺权；
- 不允许普通 shallow Top-2 永久剪掉其余候选；
- 新主核在速度未追平旧 WASM 前不得替换生产核。
