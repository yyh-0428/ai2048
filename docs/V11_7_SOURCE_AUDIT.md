## 实际策略关系

正常神级将规则配置和 `cfg.profile` 都映射为 extreme。源码中 `profile==='god'` 的较窄合并门槛与风险条件没有在这条正常路径生效。真实合并偏好门槛是 0.0005；不能据注释误称神级已使用 0.00005。V11.7 不激活这些旧死分支。

V11.5 用完整 d4 原始第一名决定是否完成 d5/d6，高分近分 d4 仅覆盖 8192/16384 与 3–4 空格。V11.6 在原始第一名相同、合并之后实际推荐不同的情况下，再完成 d6；额外检查失败便回退 d4。回退后合并偏好会再次改写出招，而且风险 verifier 由 d6 改为 d5。因此“更深复核”的拒绝并不是保留稳定旧选择。

可检验假设：仅因 d5/d6 不一致不足以支持 d4。候选在原 policy-only 检查失败时，额外要求 d4/d6 原始第一名和实际推荐均一致才恢复 d4；否则保留稳定基线的完整 d5。它将标记为证据未确认，而不是共识通过。其他原始评分分歧路径不改动。

终局底值补救是另一独立变化：全部完整根评分等于 float32 1e-6，生存全部完成且概率有效、安全总量界成立才允许严格正差改向。不能假定这项补救能修复高分中段的回退。实验分别开关。另测“原始分歧也按 d5/d6 实际出招一致采用 d6”的候选及其与补救组合；均以完整终局消融决定撤回，不以单局最高分选策略。

风险复核只在原有脆弱性条件满足时触发；完整生存差距还须达到原门槛并通过独立旧评价器。d5/d4 的改变会改变 verifier 深度。部分轮次或生存概率不进入决策。第一分歧报告保存各层根分数、原始与实际推荐、脆弱性和完整后续路径；局部第一步修复不等于整条路径恢复。

## 性能与正确性

候选不更改 C/WASM、评价权重、TT 大小、概率截断、节点上限或质量保障。历史扩 TT 会改变近似评分，因为路径概率不在键中；额外叶缓存有 41% 耗时退步；广泛加深、阈值/权重试验也有明显反例，因此不重复这些失败调参。

共同优化仅减少包装开销：根棋盘只打包一次，两份 uint32 消息在各次加深复用，Worker 重新校验 unsigned 范围/深度/质量界；保留原棋盘消息兼容入口。固定棋盘另做传原棋盘与打包消息的同源码消融。其余为：预计算逆方向映射；合法根整数幂验证和 clz rank 打包；风险脆弱性复用已生成根棋盘，出生循环避免临时二元数组。同策略同棋盘需核对评分、深度与最终方向，不能仅核对动作合法。性能与策略结果独立报告。

全部合法根继续完整同深度比较。保留质量/视野证书、32768/65536 边界、WASM 缺失和宽位 JS 兼容、取消机制、按模式/选项/规范棋盘隔离的结果缓存。只有白名单布尔实验开关进入配置与缓存键；页面不暴露未验收候选。会保留深入 V11.6 的拥挤盘高速 d5 路径。

构建器同时同步外部价值和生存 WASM，校验内嵌标记后生成 HTML。最终回归直接比对 HTML 中的规则、协调器、worker 与当前源码，以及两份模块的逐字节一致。旧存档 codec 和浏览器存储键保留，导出文件名改为 V11.7。启动脚本保留可执行权限并做 shell 语法检查；Node/Linux DOM+真实 Worker 测试不冒充 macOS 原生测试。

## 合并偏好独立消融与最终冻结

原双共识回退56局开发后，补测关闭合并偏好的稳定搜索策略8局。V11.4曾收窄另一条始终d6的God路径，其依据仅是1500步中间成绩，不能当本轮终局证据。rawNoMerge对稳定基线6胜2负，均值/中位数/尾部改善，但相对V11.6神级均值仍退步，seed-4/103明显早死。因此它仅作为最终冻结候选：只关合并偏好，不改评分和完整搜索深度。选择变更依据为已知开发样本，发生在任何新起点候选终局测试之前；最终对两个基线的全部预定验收门槛不变。初始双共识冻结和变更理由均保留。若不通过，不升级默认策略。


## 独立验收失败后的继续迭代

rawNoMerge 未通过独立20起点、两遍终局的预定验收，全部失败指标公开；因此撤回。随后冻结 retain5Promotion，在旧8个开发起点上隔离“按d5/d6实际推荐共识触发”与“采用d6评分”的影响：只改为保留完整d5评分及相应verifier深度。

8局完整出招与出生流全部等同此前失败的promotion，虽然718次请求的完成评分和深度发生变化。这个结果不支持将推广候选的退步归因于采用d6评分，提示更应关注放宽实际推荐共识的触发条件。它仍是本样本的消融观察，不是全局因果证明。候选未通过预定开发筛选并撤回，没有复用先前20个验证起点冒称新独立验证。准确冻结源码、复现命令、逐局数据与对照见 V11_7_RETAIN5_PROTOCOL / ABLATION / DECISION；npm run benchmark:v117:retain5 可以复测。


## 最终默认策略处理

原协议曾预设失败后恢复 V11.5 基线。但独立数据表明该回退的均值、最差25%和早死指标均劣于 V11.6，不能将其发布为稳定性升级。因此撤销尚未发布的回退，最终默认维持用户输入的 V11.6 神级策略，保留原共识检查与终局补救；所有新增策略仍关闭。

这偏离了原先的回退预案，已明确记录在 V11_7_DEFAULT_POLICY_DECISION.json，没有改动候选验收门槛或把失败改成成功。最终源码另做默认神级同评分、深度、出招核对与20局终局检查；它们是发布一致性复核，不是新独立增强证据。三个其他模式在该次变更中没有改变策略分支，其已完成同名对照使用准确冻结源码。神级增强目标未达成。
