- 保留 V9.1 普通 WASM 核心、预算、阶段限深与风险验证规则。
- 可复用线程池与最近一次同局面分析；初始化不计入搜索预算。

- 修复混合评分、终局截断及大数字表示，加入共同深度的渐进兼容搜索。
- 固定棋子节点、节流渲染和指标，移除强制布局。
- 手机底部操作区、改善对比度、读屏信息和键盘行为。
- 本地进度/设置保存，Mac 固定端口与进程身份检查。

完整证据和未验收项目见 `V9_2_REVIEW.md` 与 `V9_2_BENCHMARK_RESULTS.md`。
