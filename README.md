# 2048 AI · V11.8

一个**完全离线、本机计算**的 2048 AI。单文件 HTML 打开即用，不需要账号、不需要联网、不上传任何数据。引擎用 bitboard Expectimax 主搜索，叠加三态安全证明、生存检查和独立 verifier 风险层；神级档在此之上还有高分残局共识复核与一组默认关闭的实验规划器。

> 本仓库是 **V11.8 检查点版本**：默认神级策略与 V11.6 完全一致，新增的反事实续命规划 / 学习型生存谱等候选**默认关闭**，尚未通过独立终局验收。详见 [版本状态](#版本状态)。

---

## 特性

- **离线单文件**：`2048-ai.html` 双击即可运行，全部计算在本机完成。
- **四档思考强度**：轻快 / 深入 / 极致 / 神级，速度与棋力可调。
- **WASM + JS 双引擎**：bitboard WASM 核心，大数字（32768+）自动走 JS 兼容路径。
- **多线程搜索**：协调器 + 最多 4 个计算 Worker，通过 MessagePort 直接调度，减少主线程绘制与消息延迟。
- **风险层**：三态安全证明（safe / not-certain / unknown）+ 有限视野生存检查 + 独立复核，危险方向才触发深搜。
- **自动玩 / 撤销 / 存档导入导出**，存档跨版本兼容。

## 快速开始

**方式一：直接打开**

双击 `2048-ai.html`（现代浏览器即可）。

**方式二：macOS 本地服务（推荐，存档更稳）**

双击 `启动 2048 AI.command`，浏览器自动打开 `http://127.0.0.1:20480/`；停止服务双击 `停止本地服务.command`。

> 本地服务始终使用同一端口与同源地址，因此分数、设置、进度可以持久保存。直接打开 HTML 与走本地服务属于不同浏览器存储来源。

## 思考强度

| 档位 | 说明 |
|---|---|
| 轻快 | 优先速度，固定价值核心 d3 |
| 深入 | 高速拥挤盘精算，>2 空格用 d4、≤2 空格用 d5 |
| 极致 | 高速残局深搜，含高分近分复核 |
| **神级** | 高分残局共识复核 + 风险复核；默认与 V11.6 神级策略一致 |

## 工作原理（摘要）

1. 页面只提交棋盘、接收完整结果；协调器做 D4 规范化并枚举全部合法根方向。
2. 价值核心用 64-bit bitboard、65536 行移动/评价表、90% 2 / 10% 4 出生、所有出生格枚举与概率截断。
3. 风险层：主搜索给出候选 → 脆弱性门槛判断是否复核 → 三态安全证明 → 必要时跑 Survival → 生存差距达标才做更深独立复核。
4. 神级额外做「高分残局共识复核」：在最大块 8192/16384、3–4 空格、d4 前二相对差 ≤0.05% 时，用 d6 作为证据确认方向；确认失败回退完整 d4。
5. 新实验模块（反事实续命规划、学习型生存谱、模拟终点复核、证据仲裁）都有独立布尔开关、纳入缓存键，**只在神级读取且默认关闭**。

更完整的架构、边界与必须保留的约束见 [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md)。

## 多版本对比结论（本机实测）

用 8 个真实高分残局（4 局约 17 万分 + 4 局约 23 万分）作起点，恢复棋盘、分数、累计步数与完整随机流，各版本跑到终局（严格配对，面对相同方块序列）：

| 版本 | 平均额外存活 | 平均终局分 | p95 单步耗时 | 早死(≤500步) |
|---|---|---|---|---|
| V11.6 | 4538 步 | 319,482 | 4.4 ms | 1/8 |
| V11.7（正式） | 4538 步 | 319,482 | 4.5 ms | 1/8 |
| **V11.8（本仓库）** | **4538 步** | **319,482** | **4.3 ms** | **1/8** |
| V11.8 实验神级 | 4291 步 | 312,698 | 15.5 ms | 1/8 |
| V11.9 默认神级 | 907 步 | 222,461 | 63.5 ms | 6/8 |

- **V11.6 / V11.7 正式版 / V11.8 默认神级逐局完全一致**——三者就是同一套策略。
- V11.9 默认神级明显回退：8 局中 6 局在 500 步内死亡；关闭其 `lifetimePlanner / viabilityPlanner / reservePlanner` 后即恢复与 V11.6 一致。

完整报告与原始数据见 [`docs/V11_8_COMPARE_REPORT.html`](docs/V11_8_COMPARE_REPORT.html)、[`docs/V11_8_COMPARE_MERGED.json`](docs/V11_8_COMPARE_MERGED.json)、[`docs/V11_8_COMPARE_LATENCY.json`](docs/V11_8_COMPARE_LATENCY.json)。

## 项目结构

| 路径 | 用途 |
|---|---|
| `2048-ai.html` | 可离线双击运行的完整发布文件（构建产物） |
| `src/page.html`、`src/ui.js` | 页面、输入、绘制、自动游戏、存档操作 |
| `src/rules.js`、`src/session.js` | 2048 规则与存档校验 |
| `src/coordinator.js` | 调度 Worker；规范化棋盘、分发根方向、风险复核、结果缓存 |
| `src/worker.js` | 计算 Worker；内嵌 WASM 与大数字 JS 兼容引擎 |
| `src/counterfactual.js` | 公开棋盘生成虚拟未来、配对续命模拟与仲裁门槛 |
| `src/learned-survival.js`、`models/` | 64→32→3 条件生存谱、三模型共识与训练数据 |
| `v102_ai.c/.wasm` | bitboard Expectimax 核心（保留旧文件名以兼容构建与测试） |
| `survival_v9_1.c/.wasm` | 有限视野生存检查 |
| `tests/`、`archive/` | 回归测试与仍被测试使用的旧样本（非运行依赖） |
| `tools/` | 无网络构建、测试入口、交替 A/B 基准 |
| `docs/` | 升级报告、设计、协议、对比测试与原始数据 |

## 构建与测试

需要 Node.js，**无需 `npm install`**，全程无网络。

```sh
npm run build          # 由 src/ 重新构建 2048-ai.html（同步两份 WASM 内嵌字节）
npm test               # 回归测试
npm run benchmark:v118 # 神级性能基准
npm run benchmark:v118:latency
npm run replay:v118    # 终局回放校验
```

复测会另写带时间戳的文件；仅显式 `RESUME=1` 可恢复匹配策略/随机流的中断报告。基准时不要同时运行其他 CPU 密集任务。

从 C 源码重编译 WASM 需要带 WebAssembly 目标和链接器的 clang；编译器版本可能改变浮点与模块布局，重编译后必须再跑构建、测试和基准。
