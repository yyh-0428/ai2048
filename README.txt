2048 AI V9.3
============

快速开始
--------
1. 完整解压文件夹。
2. macOS 双击「启动 2048 AI.command」。首次受阻时，可在 Finder 右键选择“打开”。
3. 也可以直接打开 2048-ai.html；整个游戏不依赖网络、账号或额外安装包。
4. 「停止本地服务.command」只停止本文件夹启动的服务。

怎么玩
------
方向键 / WASD / 在棋盘滑动：移动。
空格：开始或暂停自动玩；Esc：暂停；H：提示一步；M：声音开关。
撤销：当前页面会话最多保留最近 60 步；自动玩暂停后可撤销。
刷新可恢复棋盘、分数和步数，但不恢复撤销历史。
合成 2048 后可以继续冲更大的数字。

轻快：优先速度；深入：均衡思考；极致：更多残局复核。
走棋间隔只改变观看节奏，不改变搜索预算。0 ms 取消额外等待。
手机的“提示一步”和“自动玩 / 暂停 AI”固定在底部。
本局进度、最高分、强度、间隔和声音设置保存在当前浏览器本地。
清理浏览器数据会清除记录；文件模式与本地服务模式有不同的保存位置。

本次升级
--------
针对 32768+ 或 WASM 不可用时的 JavaScript 兼容搜索，增加：
- 完整棋盘叶值缓存：比较全部 128 位棋盘后才复用原始评分，避免散列碰撞误判。
- 可逆出生遍历：减少 2/4 分支的棋盘复制，超时退出时也恢复状态。
- 行移动直接查表与按序搜索：减少临时数组和同时存活的移动棋盘。

这是为本项目自行编写的等价优化组合；不宣称记忆化/回溯原理为学术首创。
普通 WASM、Survival、三档配置和 Verifier 维持原样。
保留 V9.2 的调度线程、状态取消、存档、无障碍与离线运行能力。

验证结果
--------
- 202 个局面，普通与兼容路径各 739 个根方向，重复三轮：
  共 4434 次新旧配对，固定深度的评分和逻辑节点数全部相同。
- 大数字兼容路径平均耗时约降低 36.31%，P95 约降低 35.36%。
- 普通 WASM 字节不变；普通整步响应的三档平均差异均在约 1% 以内。
- 详细回归、完整对局结果、环境与证据限制见 docs/V9_3_BENCHMARK_RESULTS.md。

这些是 Node 真实 Worker 实测，不能保证所有设备恒定加速或每一局得分更高。
固定深度等价不等于时间预算下必走同一方向；运行更快可能完成更多层搜索。
普通主核未修改，不能把普通整局的小样本得分变化归因于棋力升级。

开发与复现
----------
仅开发与测试需要 Node（本次使用 Node 24）：
  npm run build
  npm test
  npm run benchmark:fixed
  npm run benchmark:latency
  npm run benchmark:games -- 6
  npm run report

完整复现：
  npm run build
  npm test > docs/v9.3-regression.log 2>&1
  npm run benchmark
  npm run report

请顺序执行计时实验，避免竞争 CPU；扩大样本可使用：
  node tests/benchmark-v9.3.cjs games 50
BENCH_OUTPUT 环境变量可指定新的结果 JSON；报告默认读取 docs/v9.3-results.json。

src/ 是源码；2048-ai.html 是构建的单文件应用。
tests/fixtures/v9.2.html 是上传版基准；v9.1.html 保留更早版本。
docs/V9_3_RESEARCH.md 记录研究来源、算法论证、内存成本与取舍。
READ_FIRST_V9_3.md 是当前护栏；旧版报告保留供追溯，不算作本版新证据。
docs/history/v9.2/ 下的旧测试/报告脚本只存档，需恢复完整 V9.2 项目才可运行。

限制
----
每个启用兼容引擎的计算线程增加 200 KiB 叶缓存，四线程共 800 KiB；
正常 WASM 使用不分配该缓存。
老 WASM 的评价器阶段跳变与内部对称性问题仍在，不宣称已经修复。
本环境没有可用浏览器及 macOS，未完成 Safari/Chrome 真实点击或 Mac 启停验收。
后台限速、CPU 竞争、设备温度仍可能影响速度。
